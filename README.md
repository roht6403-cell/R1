# Offline Mail Merge Android Project

हा prototype Android app CSV मधून प्रश्न वाचतो आणि निवडलेल्या Questions/Page प्रमाणे A4 PDF तयार करतो.

## सध्या
- CSV import
- Questions per page (default 10)
- Offline PDF generation
- A4 PDF
- कोणताही server/API नाही

## महत्त्वाचे
हा पहिला prototype आहे. XLSX direct import, drag-and-drop template editor, Marathi font embedding आणि PDF share/export UI पुढील आवृत्तीत जोडता येतील.

## CSV format
पहिली row header:
Question
नंतर प्रत्येक row मध्ये एक question.
